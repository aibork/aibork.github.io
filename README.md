# Axel Bork — Portfolio

Portfolio personal de Axel Bork, Jefe de Ingeniería en Supply Chain.

🔗 **Sitio:** https://aibork.github.io/

## Contenido

Sitio de una sola página, disponible en español e inglés, con las secciones:

- Perfil
- Experiencia
- Proyectos
- Formación
- Herramientas
- Referencias
- Contacto

## Estructura

Todo el sitio está en un único archivo, `index.html` (HTML, CSS y JavaScript inline), publicado con GitHub Pages desde la rama `main`.

## Desarrollo local

Abrí `index.html` en el navegador. No requiere instalación ni build.
